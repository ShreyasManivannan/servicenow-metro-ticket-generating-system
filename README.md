# servicenow-metro-ticket-generating-system
Metro Ticket Generating System in ServiceNow
A digital metro ticket booking and QR-based ticket generation system developed using ServiceNow. The system simplifies metro ticket booking by allowing users to select stations, enter travel details, automatically calculate fares, and generate digital tickets through QR codes.

📌 Project Overview
The Metro Ticket Generating System is designed to modernize the metro ticket booking process using ServiceNow's automation and Service Catalog capabilities.

Users can enter their travel details through a Service Catalog form. The system validates the entered information, calculates the fare based on the selected stations and passengers, and generates a QR-based digital ticket after successful submission.

✨ Key Features
🚉 Source and destination station selection
🎫 Digital metro ticket booking
💰 Automatic fare calculation
👥 Passenger-based fare calculation
🔄 Single and return journey support
✅ Mandatory field validation
👁️ Conditional field visibility
⚙️ Automated field mapping and population
📱 QR code-based digital ticket generation
🔔 Automated notifications
🔐 ServiceNow-based data and access management
